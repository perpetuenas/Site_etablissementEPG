# Site_etablissementEPG
présentation
Mini site web de présentation d'un établissement avec quelques formations et les coordonnées de contact.
Objectifs:
Présenter l'établissement;
Mettre en valeur les formations;
Faciliter l'accès aux informations et aux contacts;
Technologies utilisés: HTML5,CSS et Javascript
Outil utilisé: Visual Studio Code 
Statut: Projet réalisé en local,le site n'est pas publié en ligne.
